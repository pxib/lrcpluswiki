# Original Cantonese font sources

These unchanged WOFF 1 wrappers of the user's installed Regular TrueType
fonts were previously published under `docs/manual/assets/fonts/`.
They are retained here as reproducible input to `tools/build-fonts.py` and
are outside the GitHub Pages upload directory.

Both fonts remain under the SIL Open Font License 1.1; see
[`OFL.txt`](../../docs/manual/assets/fonts/OFL.txt) and the
[font documentation](../../docs/manual/assets/fonts/README.md) for provenance,
generated subsets, and rebuild instructions. The repository MIT license
does not replace the font license.
