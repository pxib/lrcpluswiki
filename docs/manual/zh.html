关于本手册

本手册描述了 LRCPlus 当前源版本中的控件。可用功能可能会因您的构建和启用的插件而异。 Settings → Lyrics 等菜单路径描述了在应用程序中单击的内容。

本手册可在线获取并与应用程序捆绑在一起。捆绑副本支持离线阅读和搜索。检索歌词或使用在线注音服务的功能仍然需要互联网连接。

安装和设置

从下载到您的第一首歌曲

安装 LRCPlus，完成初始设置，并在添加可选功能之前检查音乐是否播放。

开始之前

发布的下载是 Windows x64 版本。检查发行说明以了解与您的 Windows 版本的要求和兼容性。准备一个本地音频文件来测试播放。下载应用程序和使用在线服务需要连接互联网；本地音乐、本地歌词和捆绑的手册可以离线使用。

下载并解压

  1. 打开官方最新版本并阅读其发行说明。使用稳定版本进行日常聆听。
  2. 在 Assets 下，下载 LRCPlus-<version>-Windows-x64.zip。 GitHub 源代码档案用于从源代码运行或开发；它们不是打包的应用程序。
  3. 在文件资源管理器中右键单击下载的 ZIP，然后选择 Extract All…。将整个存档解压缩到您可以写入的文件夹，例如您的用户帐户下的文件夹。
  4. 打开解压的文件夹并运行LRCPlus.exe。将其支持文件和子文件夹放在一起；不要仅移动可执行文件或从 ZIP 内部运行它。

打包的应用程序包括其 Python 运行时；您无需单独安装 Python 即可启动它。要从源代码开始工作，请遵循 源存储库 及其依赖项说明。

完成首次运行设置

如果出现设置向导，请按照 Ayami 的提示并选择提供的外观和歌词首选项。您可以稍后在 Settings 中调整它们。同伴聊天是可选的：播放音乐不需要 AI 提供商或 API 密钥。如果您想配置聊天，请参阅 配套指南 。

  1. 音乐库：如果您想在安装过程中构建音乐库，请添加一个音乐文件夹。
  2. 外观：选择提供的主题和预设。
  3. 阅读偏好和歌词：选择您想要的阅读辅助工具和歌词显示选项。请参阅 Furigana 和注音 了解提供商要求。
  4. 继续准备聆听，然后在播放器中测试播放。

要重新访问设置，请选择 设置 → 常规 → 重新启动向导 。如果返回用户伴随窗口打开，请选择 再次运行设置 以返回到原始向导。

添加音乐并测试播放

  1. 选择“Open”→“打开音频...（Ctrl + O）”，选择本地音频文件，然后选择“Play”。
  2. 对于音乐收藏，切换到 Library，选择 添加音乐文件夹 ，然后选择您的音乐文件夹。更改文件后使用 Rescan。
  3. 按照入门 附本地歌词文件或在线搜索歌词。

设置可选功能

打开 Settings → Plugins 查看您的构建包含哪些插件以及它们是否已启用。检查 Settings → Dependencies 或插件的 Dependencies 按钮是否缺少包和可用操作。按照 插件指南 安装所需功能的要求。在线提供商可能还需要连接、凭证或语言模型。

对于日语注音，请参阅 Furigana 和注音 ；歌词翻译请参见Translations。

如果设置不起作用

  • 应用程序无法打开或报告丢失文件： 确保提取完成，然后尝试将完整的 ZIP 提取到新文件夹中。将所有捆绑文件放在一起，并检查下载的内容是否与您的系统匹配。
  • 音乐无声播放：检查静音、播放器音量和Windows混音器音量。在设置→播放中，尝试将System Default作为输出设备，然后尝试另一个音频文件。
  • A 插件或注音服务不可用： 检查其启用状态、加载错误和依赖项。按照其指南进行任何外部服务设置。
  • 仍然卡住？ 请参阅 故障排除 。对于启动失败，请包含发布文件名、您的 Windows 版本以及确切的错误；如果应用程序打开，还请包含 Settings → About 中的版本。

开始使用

你在《LRCPlus》中的第一首歌

LRCPlus 新手？从 安装和设置 开始。

LRCPlus 在同步歌词的同时播放音乐，并配有可选的阅读辅助工具和卡拉 OK 计时功能。您可以从单个音频文件开始。

播放你的第一首歌曲

  1. 启动LRCPlus。如果出现安装向导，请按照其提示进行操作。
  2. 选择“Open”→“打开音频...”，或按“Ctrl + O”，然后选择一个音频文件。
  3. 使用 Play 开始或暂停播放。
  4. 选择 Lyrics 切换到歌词显示，或选择 Library 返回到您的音乐。

添加歌词

如果您有匹配的歌词文件，请选择 Open → 打开歌词… (Ctrl + L)。否则选择 LRC → 搜索歌词 在线查找。请参阅 查找歌词 了解完整的工作流程。

尝试匹配的文件名。 保留 Song.mp3 和 Song.lrc （或 Song.lrcx）在一起。当两种歌词格式都存在时，LRCPlus 更喜欢 LRCX。

接下来怎么办？

  • 将音乐文件夹添加到库中。
  • 打开注音假名或罗马字。
  • 修正歌词。

您可以从 设置 → 常规 → 重新启动向导 重新打开设置向导。

音乐和播放

您的库、队列和播放控件

建立音乐库

  1. 切换到 Library。
  2. 单击 添加音乐文件夹 并选择包含您的音乐的文件夹。
  3. 更改音乐文件夹中的文件后，使用 Rescan。

使用 Remove Folder 来管理哪些文件夹属于该库。

使用队列

选择 Open → 添加到队列… (Ctrl + Shift + O) 添加文件。播放源选择器提供Library和Queue/Playlist；如果玩家前进的曲目与您预期的不同，请检查此选择器。

导航轨道

控制它的作用
播放/暂停开始或暂停当前曲目。
停止停止播放。
< 5 秒 / 5 秒 >向后或向前移动五秒。
<< / >>移至上一个或下一个曲目。
音量/静音调整或静音输出。

播放首选项

在 设置 → 播放 中，选择输出设备、曲目或专辑随机播放，以及播放后发生的情况：下一曲目、停止、重复全部或重复曲目。如果您不确定要使用哪个设备，请从 System Default 开始进行输出。

请参阅 键盘快捷键 以快速访问播放和工作区控件。

寻找歌词

加载文件或搜索正确的版本

打开本地歌词

加载您的歌曲，然后选择 Open → 打开歌词… 并选择 .lrc 或 .lrcx 文件。将文件名与音频匹配有助于自动发现。您可以在 设置 → 文件 中管理其他歌词搜索文件夹。

网上搜索

  1. 加载您想要歌词的歌曲。
  2. 选择 LRC → 搜索歌词。
  3. 查看搜索详情，然后单击“Search”。
  4. 选择一个结果并阅读其预览。检查艺术家和歌曲版本，尤其是现场录音和混音。
  5. 单击“使用所选歌词”以应用该结果。

一些提供商需要凭据。 LRCLIB 集成支持同步和纯文本歌词。在线搜索需要连接。

同步与纯文本

同步歌词包含时间戳，告诉播放器每行何时开始。简单的歌词提供了没有这些时间的歌词。如果出现文本但未跟随歌曲，请检查结果是否包含时间戳。您可以将它们添加到歌词编辑器中。

保留本地副本

使用 LRC → 另存为… 将歌词保存到您选择的文件中。当您需要阅读、卡拉 OK 计时或格式化时，首选 .lrcx。检查您的保存位置，以便您可以再次找到该文件。

振假名与注音

歌词阅读辅助工具

振假名是显示在日语歌词旁边的小号注音。罗马字使用拉丁字母表示读音。保存的 LRCX Ruby 标记也可以提供手动编写的注音。

选择注音显示

  1. 打开设置→歌词。
  2. 选择 Global 作为一般默认值，或选择 Local（文件） 作为当前文件。
  3. 启用 显示注音假名 、 显示罗马字 或 所有罗马字 。这些模式是互斥的。
  4. 使用 Ruby 位置 将注音放在歌词上方或下方。

选择自动解析器

解析器要求
Yomi在线日语注音服务，需要连接互联网。
MeCab本地可选解析器；需要fugashi和单独安装的字典。

解析器选择器位于歌词设置中。请参阅 设置 → 依赖关系 以获取依赖关系信息。

生成并纠正注音

打开 LRC → 编辑 Lyrics，然后使用 Generation 选项卡。选择 生成所有歌词的注音 或 生成此时间戳 。自动读取的名称、异常拼写和双关语歌词可能会出现错误；保存前检查它们。

要在 LRCX 中保留作者阅读内容，请使用 {base|reading}，例如 {君|きみ}。请参阅 LRCX 参考 。

编辑和计时

纠正单词并让它们跟随音乐

加载歌曲并选择 LRC → 编辑歌词。在进行重大时间更改之前保存单独的副本。

编辑歌词行

在 Lyrics 选项卡中，选择一行并编辑其文本。使用+添加行、删除行、上移和下移来管理文档。格式控件包括粗体、斜体、删除线、下划线和 Quote。

设置线路时序

  1. 选择您想要计时的线路。
  2. 使用编辑器播放控件查找该行的开始位置。 Waveform 控件可帮助您检查音频。
  3. 在行开头使用 标记播放时间 。这将更新所选行并前进到下一行。当调整临时波形标记时，请使用 Commit 应用其时序。
  4. 再次播放该段落并检查歌词是否跟随音乐。

使用 Shift Timing... 进行一致的时序调整，并使用 Validate Timing 检查时序问题。在应用广泛的转变之前测试一小部分。

时间卡拉OK片段

在 Karaoke 选项卡中，使用 自动分离 准备段边界，检查它们，然后选择 应用分离 。在处理片段时使用 Mark 播放时间 [F]。回听以验证结果；自动分离并不能保证准确的计时。

源文本与保存

Source 选项卡显示定时歌词文本。 Refresh Source 和 Reload from Source 在结构化编辑器和源文本之间移动。在重新加载可能替换编辑的源之前保存副本。

另存为 .lrcx 以保留 LRCX 功能。有关语法和示例，请参阅 LRCX 参考 。

LRCX参考

增强歌词文件的实用指南

LRCX 通过卡拉 OK 片段计时、Ruby 朗读和文本格式扩展了 LRC。普通的 LRC 文件仍然有效。

时间戳

[00:12.500]The line begins here
[00:16.000]<00:16.000>One <00:16.500>word <00:17.000>at a time

方括号时间戳标记行开始。尖括号时间戳标记卡拉 OK 片段的开始。时间使用分钟、秒和毫秒。

Ruby 注音

[00:12.500]{君|きみ}の声

|之前的文本是基础歌词；后面的文字就是阅读内容。

设置行格式和显示行

语法效果
**bold**大胆
*italic*斜体
~~text~~删除线
<u>text</u>下划线
{\n}同一时间行中的新视觉行
> text紧接在行时间戳之后放置的块引用
[00:12.500]**First row**{\n}Second row
[00:16.000]> A quoted lyric

视觉换行标记是文字文本 {\n}，而不是新时间戳。在编辑器中，使用 Insert Newline {\n}。

元数据和兼容性

[ar:Artist]
[ti:Song title]
[al:Album]

使用 .lrcx 扩展来保留这些增强功能。其他歌词播放器可能无法理解扩展名。当您需要与其他播放器兼容时，请保留普通的 LRC 副本。

有关完整的格式规范，请参阅项目源中的 LRCX_SPEC.md （可能需要 Markdown 阅读器）。

定制化

让玩家轻松阅读和使用

外观和背景

打开 设置 → 外观 选择浅色或深色主题，更改强调色以及保存、导入或导出主题。高级颜色控制可让您调整单独的界面颜色。

在 设置 → 背景 中，选择艺术作品源或自定义背景文件夹并调整背景处理。如果歌词文本难以阅读，请从简单的背景开始。

歌词布局

在 设置 → Lyrics 中，选择紧凑或滚动显示、书写方向、对齐方式、字体和阅读选项。自动滚动遵循时间戳；连续滚动的移动独立于它们。滚动行为控制当前歌词如何保持在视图中。

全球还是本地？ 使用 全球 满足您的正常喜好。检查 本地（文件） 当一首歌曲的表现与其他歌曲不同时。

卡拉OK外观

使用 设置 → Karaoke 自定义卡拉 OK 显示。逐字进行需要歌词文件中的分段计时；外观设置无法添加缺失的计时。参见编辑和计时。

可选功能

其他设置和控件可能来自插件，包括可选的配套功能和集成。打开 Settings → Plugins 查看您的安装中可用的插件及其设置。

插件

管理可选功能

启用并配置

  1. 打开设置→插件。
  2. 按名称找到插件并阅读其说明。
  3. 使用其 Enabled 复选框来更改是否启用。核心插件无法禁用。
  4. 如果出现 Settings 按钮，请使用它来配置该插件。

某些更改可能需要重新启动应用程序。如果应用设置后未出现预期的控件，请重新启动 LRCPlus。

依赖关系和加载错误

插件可能需要额外的包。使用其 Dependencies 按钮，或打开 Settings → Dependencies，检查依赖关系信息。无法加载的插件可能会在其设置条目中显示错误；使用该消息来识别缺失或冲突的需求。

添加插件

插件安装特定于插件和发行版。请遵循插件作者的安装说明。源项目从其 plugins 目录中发现插件；不要假设每个打包版本都公开相同的可写位置。

对于插件作者来说，单独的 Plugin API 文档 涵盖了开发（可能需要 Markdown 阅读器）。

故障排除

从您可以看到的症状开始

播放无声

  1. 检查播放是否正在运行且播放器未静音。
  2. 检查播放器音量和 Windows 混音器音量。
  3. 在 Settings → Playback 中，尝试将 System Default 作为输出设备。
  4. 尝试另一个已知有效的音频文件，看看问题是否特定于某首歌曲。

歌词不出现

切换到歌词。使用 Ctrl + L 显式打开歌词文件，或使用 LRC → 搜索歌词。检查 设置 → 文件 下的文件名和搜索文件夹。如果LRC和LRCX文件都存在，则先检查LRCX文件，因为LRCX文件优先。

歌词出现在错误的时间

确认歌词与录音相符：现场版本、混音版和不同的前奏通常有不同的时间安排。检查文件是否有时间戳。在编辑器中使用 Shift Timing... 以获得一致的偏移，或者当整首歌曲中的不匹配发生变化时纠正单独的行。

注音缺失或不正确

检查设置→歌词中的注音模式，包括任何本地（文件）设置。 Yomi需要连接； MeCab 需要其本地包和字典。当单词需要特定阅读时，查看自动输出并使用编写的 LRCX Ruby。

插件不可用

查看 Settings → Plugins 的启用状态和加载错误。检查 Dependency 是否缺少所需的包。如果需要，配置更改后重新启动。

报告问题

包括 Settings → About、Windows 版本、重现步骤、预期行为以及发生的情况中的 LRCPlus 版本。请注意其他曲目是否出现此问题以及是否涉及可选插件。当有助于解释时间或渲染问题时，请包含一个小歌词示例。

实际应用的编号之旅

使用这些编号视图可以找到整个手册中描述的控件。选择蓝色数字可跳转至其说明。屏幕截图显示了带有示例歌词和独立首选项的实际源界面；插件和您的主题可能会添加或更改控件。

播放器和歌词工作区

  1. 图书馆工作区。 切换回您的音乐收藏；歌词又回到了这个观点。
  2. LRC 菜单。 单击LRC 可以编辑当前歌词。它的箭头可打开“搜索歌词”、“另存为”和其他歌词操作。
  3. 歌词显示。 此处出现同步歌词。设置 → 歌词控制显示模式、字体、对齐方式和注音。
  4. 行列表。 展开或折叠定时行列表。单击展开列表中的一行可跳转到其时间。
  5. 搜索栏。 移动到另一个播放位置。在未加载音频的情况下，持续时间和搜索范围保持为零。
  6. 播放或暂停。 暂停或恢复播放。相邻按钮可停止、跳过五秒或更改曲目。
  7. Volume. 调节音量；静音使输出静音，而不丢弃保存的音量级别。

图书馆工作区

  1. 搜索库。 过滤您的库而不更改其文件。
  2. 音乐库。 添加文件夹后，曲目将显示在此处。双击曲目即可播放；右键单击列标题可管理可见列。
  3. 打开文件。打开音频加载文件；添加到队列追加文件；打开歌词会附加歌词文件。
  4. Settings. 打开首选项。使用类别列表和设置搜索来查找选项。
  5. 播放控件。 传输控件在两个工作区中均保持可用。选中播放来源以选择库或队列/播放列表。

歌词编辑

  1. 编辑器工作区。 在歌词、生成、源、共享和高级之间切换。可选插件可以添加工作区。
  2. 定时歌词行。 选择要编辑的行。搜索、上一个、下一个和顺序选择器有助于导航长文档。
  3. 标记播放时间。 在所选行上标记当前播放时间并前进到下一行。在计时之前加载音频。
  4. Save. 保存写入更改并保持编辑器打开。保存并关闭写入并退出；当没有更改时，保存将被禁用。

设置窗口

  1. 设置类别。 选择类别。类别上方的搜索字段可帮助按名称查找设置。
  2. 无间隙播放。 启用下一曲目预缓冲。这需要FFmpeg和正常的速度和音调；它在下一曲目上生效。
  3. 输出设备。 选择输出设备。系统默认值遵循系统选择的输出。

设置参考

选项、出厂默认值及其适用范围

此参考列出了播放器和歌词控件及其出厂默认值。保存的首选项、设置预设或每个文件覆盖可能会产生不同的值。打开Settings并选择命名类别；当您知道选项名称时，请使用设置搜索。

全局设置和文件覆盖

大多数类别都适用于该应用程序。 Lyrics → Global 提供歌词显示默认值，而 Lyrics → Local (File) 则覆盖当前文件的选定选项。没有覆盖的文件继承全局值。自动日语解析器是 global-only 选择。卡拉 OK 外观和播放偏好也是应用范围内的。

如果一个文件看起来不同，请先检查本地（文件）。文件覆盖与其文件路径相关联；它与 LRCX 文档中存储的注音、时间戳和格式不同。

翻译

将原始歌词和翻译行放在一起

选择提供商

在设置 → 插件中启用 Lyrics Translator。加载带有定时歌词的歌曲并打开 LRC → 编辑歌词 → 翻译。从提供商选择器中选择一个提供商。如果该选项卡不存在，请检查翻译提供程序是否已启用并加载。

Argos 使用可选的本地包和下载的语言模型。云提供商需要连接并且可能需要凭据。可用的提供商和语言路线显示在应用程序中。

翻译、审阅并保存

  1. 如果当前歌词文档尚未显示，请将其加载到面板中。
  2. 选择源语言和目标语言，然后选择要翻译的行或缺失的行。
  3. 选择 翻译缺失的行 或 翻译选定的行 。读取并编辑输出；自动翻译可能会漏掉名字、双关语或上下文。
  4. 选择应用到歌词编辑器，然后使用保存或保存并关闭。

使用翻译显示行时，保留原始行并另存为 LRCX。 “歌词”选项卡还具有 插入翻译 {\nt}，用于在时间线内创作翻译。

使用现有翻译

搜索歌词包括原始和翻译预览。当结果提供翻译的歌词时，对其进行查看并使用 Apply Only Translation 保留当前的原始文本。

如果无法翻译

检查提供商、语言路线、所需的型号或凭据以及连接。对于 Argos，检查可选的依赖项和模型文件夹。对于云服务，请注音服务错误。歌词显示语言和翻译目标是单独的选择。

分享和图像卡

导出文本或制作歌词图像

复制或导出文本

  1. 打开LRC→编辑歌词→分享→文本。
  2. 对于单独的单词，选择 纯文本 ；对于定时行，选择 带行时间戳 。
  3. 使用 Copy 作为剪贴板，或使用 Export… 作为文件。

这共享歌词文本，而不是音频。使用编辑器保存操作来保存完整的可编辑 LRCX 文档。

创建图像卡

  1. 在编辑器中打开Share → 图片卡。
  2. 使用选中的行选择选择摘录并查看预览。
  3. 选择布局模板，然后调整文本、图稿和背景设置。
  4. 使用卡控件导出图像。

模板包括经典、聚光灯、唱片套、宝丽来、编辑和影院。艺术品是可选的；电影院可以使用专辑封面作为模糊背景。

阅读和格式化

保留 LRCX 格式 保留内联强调、引用样式、视觉中断和较小的翻译行。汉字注音是单独控制的，并使用创作的或已经生成的注音；图像卡不启动注音服务。首先在编辑器中生成缺失的注音。

版式支持水平和垂直书写。歌曲详细信息包括标题、艺术家或制作人员以及专辑。导出前检查预览是否有被剪裁的文本或丢失的字体字符。卡上未打印时间戳和播放卡拉 OK 突出显示。

对话与记忆

设置对话使用 LRCPlus 受 Ren'Py 启发的脚本引擎。编写的分支和事件跟踪让 Ayami 对选择、主题、窗口移动和其他支持的事件做出反应。此脚本对话与可选的 AI 聊天分开，后者的回复来自配置的模型。

脚本变量和对话状态也与保存的聊天对话和内存事实分开。聊天使用提供的对话和启用的记忆；它不会接收您的歌曲、歌词或播放器设置，并且其回复无法执行应用程序操作。请参阅 内存控制 以选择消息中保留和包含的内容。

Ayami 的可选聊天出现在启用伴侣的设置向导中。使用 设置 → 常规 → 重新启动向导 重新访问设置。聊天与音乐播放是分开的，不需要配置来播放歌曲。

配置聊天

打开 AI 设置... 并输入兼容提供商的 API 基本 URL、型号 ID 和密钥。本地服务器可能不需要密钥。内置按键帮助解释了提供程序设置。保存，输入消息，然后选择 Send。 Regenerate 请求另一个响应；停止取消正在运行的请求。

发送与所选提供商共享对话、角色指令和启用的记忆。不附带歌曲、歌词、设定。记住的密钥和自定义标头使用 Windows 帐户加密（如果可用）；否则它们仍仅用于会话。

保存的对话

使用保存的对话选择器来切换聊天。 新对话开始另一个对话； Rename 和 Delete 管理已保存的对话。上一页和下一页导航较长回复的页面。

控制保存的记忆

打开 Memories... 编辑事实，每行一个，并选择是否将它们包含在以后的消息中。最多允许 20 个事实，每个事实 200 个字符。

自动记忆模式提供关闭、建议批准（默认）和自动保存普通偏好设置。提取可以使用额外的提供者请求。使用“审查”接受或驳回建议，使用“来源”检查其来源，使用“立即检查”请求检查，或使用“停止检查”取消建议。

工作教程

三个小任务，从开始到结束

为你的第一首歌计时

  1. 打开音频，然后打开编辑器并按文档顺序添加歌词行。
  2. 选择第一行并使用编辑器控件开始播放。
  3. 在该演唱行的开头，选择 标记播放时间 。编辑器对其进行标记并前进到下一行。
  4. 重复，然后回听并纠正迟到或早到的分数。
  5. 选择 Validate Timing，查看结果并保存副本。

从三到四行开始。逐段卡拉 OK 计时是可选卡拉 OK 选项卡中的单独通道。

修复晚两秒的歌词

如果歌词始终在歌手开始后两秒出现，请将其时间戳 earlier 移动 2 秒。

  1. 保存备份副本。
  2. 打开 Shift Timing… 并选择预期范围，例如所有行。
  3. 使用对话框中显示的单位输入负的两秒偏移（−2 秒或−2000 毫秒）。正值会稍后移动歌词。
  4. 听靠近开头和结尾的地方。如果不匹配发生变化，请更正各个时间或查找正确录音的歌词。
  5. 验证并保存。撤消可在编辑时反转转变。

Shift Timing 改变时间戳；单独的歌词偏移量保持不变。 [00:12.000] 处的线在移动 -2 秒后变为 [00:10.000]。

添加自定义注音假名

  1. 打开歌词文档，切换到Source。
  2. 保存备份，然后使用 {base|reading} 换行。
  3. 例如，将 [00:12.500]君の声 更改为 [00:12.500]{君|きみ}の声。
  4. 使用 Source 中的 Reload 将源应用到结构化编辑器。
  5. 启用显示注音假名，检查并保存为.lrcx。

撰写的读物可让您纠正姓名和不寻常的发音。
