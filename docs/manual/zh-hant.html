關於本手冊

本手冊描述了 LRCPlus 當前源版本中的控制元件。可用功能可能會因您的構建和啟用的外掛而異。 Settings → Lyrics 等選單路徑描述了在應用程式中單擊的內容。

本手冊可線上獲取並與應用程式捆綁在一起。捆綁副本支援離線閱讀和搜尋。檢索歌詞或使用線上注音服務的功能仍然需要網際網路連線。

安裝和設定

從下載到您的第一首歌曲

安裝 LRCPlus，完成初始設定，並在新增可選功能之前檢查音樂是否播放。

開始之前

釋出的下載是 Windows x64 版本。檢查發行說明以瞭解與您的 Windows 版本的要求和相容性。準備一個本地音訊檔案來測試播放。下載應用程式和使用線上服務需要連線網際網路；本地音樂、本地歌詞和捆綁的手冊可以離線使用。

下載並解壓

  1. 開啟官方最新版本並閱讀其發行說明。使用穩定版本進行日常聆聽。
  2. 在 Assets 下，下載 LRCPlus-<version>-Windows-x64.zip。 GitHub 原始碼檔案用於從原始碼執行或開發；它們不是打包的應用程式。
  3. 在檔案資源管理器中右鍵單擊下載的 ZIP，然後選擇 Extract All…。將整個存檔解壓縮到您可以寫入的資料夾，例如您的使用者帳號下的資料夾。
  4. 開啟解壓的資料夾並執行LRCPlus.exe。將其支援檔案和子資料夾放在一起；不要僅移動執行檔或從 ZIP 內部執行它。

打包的應用程式包括其 Python 執行時；您無需單獨安裝 Python 即可啟動它。要從原始碼開始工作，請遵循 源儲存庫 及其依賴項說明。

完成首次執行設定

如果出現設定嚮導，請按照 Ayami 的提示並選擇提供的外觀和歌詞首選項。您可以稍後在 Settings 中調整它們。同伴聊天是可選的：播放音樂不需要 AI 提供商或 API 金鑰。如果您想配置聊天，請參閱 配套指南 。

  1. 音樂庫：如果您想在安裝過程中構建音樂庫，請新增一個音樂資料夾。
  2. 外觀：選擇提供的主題和預設。
  3. 閱讀偏好和歌詞：選擇您想要的閱讀輔助工具和歌詞顯示選項。請參閱 Furigana 和注音 瞭解提供商要求。
  4. 繼續準備聆聽，然後在播放器中測試播放。

要重新訪問設定，請選擇 設定 → 常規 → 重新啟動向導 。如果返回使用者伴隨視窗開啟，請選擇 再次執行設定 以返回到原始嚮導。

新增音樂並測試播放

  1. 選擇“Open”→“開啟音訊...（Ctrl + O）”，選擇本地音訊檔案，然後選擇“Play”。
  2. 對於音樂收藏，切換到 Library，選擇 新增音樂資料夾 ，然後選擇您的音樂資料夾。更改檔案後使用 Rescan。
  3. 按照入門 附本地歌詞檔案或線上搜尋歌詞。

設定可選功能

開啟 Settings → Plugins 檢視您的構建包含哪些外掛以及它們是否已啟用。檢查 Settings → Dependencies 或外掛的 Dependencies 按鈕是否缺少包和可用操作。按照 外掛指南 安裝所需功能的要求。線上提供商可能還需要連線、憑證或語言模型。

對於日語注音，請參閱 Furigana 和注音 ；歌詞翻譯請參見Translations。

如果設定不起作用

  • 應用程式無法開啟或報告丟失檔案： 確保提取完成，然後嘗試將完整的 ZIP 提取到新資料夾中。將所有捆綁檔案放在一起，並檢查下載的內容是否與您的系統匹配。
  • 音樂無聲播放：檢查靜音、播放器音量和Windows混音器音量。在設定→播放中，嘗試將System Default作為輸出裝置，然後嘗試另一個音訊檔案。
  • A 外掛或注音服務不可用： 檢查其啟用狀態、載入錯誤和依賴項。按照其指南進行任何外部服務設定。
  • 仍然卡住？ 請參閱 故障排除 。對於啟動失敗，請包含釋出檔名、您的 Windows 版本以及確切的錯誤；如果應用程式開啟，還請包含 Settings → About 中的版本。

開始使用

你在《LRCPlus》中的第一首歌

第一次使用 LRCPlus？請先閱讀安裝與初始設定。

LRCPlus 在同步歌詞的同時播放音樂，並配有可選的閱讀輔助工具和卡拉 OK 計時功能。您可以從單個音訊檔案開始。

播放你的第一首歌曲

  1. 啟動LRCPlus。如果出現安裝嚮導，請按照其提示進行操作。
  2. 選擇“Open”→“開啟音訊...”，或按“Ctrl + O”，然後選擇一個音訊檔案。
  3. 使用 Play 開始或暫停播放。
  4. 選擇 Lyrics 切換到歌詞顯示，或選擇 Library 返回到您的音樂。

新增歌詞

如果您有匹配的歌詞檔案，請選擇 Open → 開啟歌詞… (Ctrl + L)。否則選擇 LRC → 搜尋歌詞 線上查詢。請參閱 查詢歌詞 瞭解完整的工作流程。

嘗試匹配的檔名。 保留 Song.mp3 和 Song.lrc （或 Song.lrcx）在一起。當兩種歌詞格式都存在時，LRCPlus 更喜歡 LRCX。

接下來怎麼辦？

  • 將音樂資料夾新增到庫中。
  • 開啟注音假名或羅馬字。
  • 修正歌詞。

您可以從 設定 → 常規 → 重新啟動向導 重新開啟設定嚮導。

音樂和播放

您的庫、佇列和播放控制元件

建立音樂庫

  1. 切換到 Library。
  2. 單擊 新增音樂資料夾 並選擇包含您的音樂的資料夾。
  3. 更改音樂資料夾中的檔案後，使用 Rescan。

使用 Remove Folder 來管理哪些資料夾屬於該庫。

使用佇列

選擇 Open → 新增到佇列… (Ctrl + Shift + O) 新增檔案。播放源選擇器提供Library和Queue/Playlist；如果玩家前進的曲目與您預期的不同，請檢查此選擇器。

導航軌道

控制它的作用
播放/暫停開始或暫停當前曲目。
停止停止播放。
< 5 秒 / 5 秒 >向後或向前移動五秒。
<< / >>移至上一個或下一個曲目。
音量/靜音調整或靜音輸出。

播放首選項

在 設定 → 播放 中，選擇輸出裝置、曲目或專輯隨機播放，以及播放後發生的情況：下一曲目、停止、重複全部或重複曲目。如果您不確定要使用哪個裝置，請從 System Default 開始進行輸出。

請參閱 鍵盤快捷鍵 以快速訪問播放和工作區控制元件。

尋找歌詞

載入檔案或搜尋正確的版本

開啟本地歌詞

載入您的歌曲，然後選擇 Open → 開啟歌詞… 並選擇 .lrc 或 .lrcx 檔案。將檔名與音訊匹配有助於自動發現。您可以在 設定 → 檔案 中管理其他歌詞搜尋資料夾。

網上搜索

  1. 載入您想要歌詞的歌曲。
  2. 選擇 LRC → 搜尋歌詞。
  3. 檢視搜尋詳情，然後單擊“Search”。
  4. 選擇一個結果並閱讀其預覽。檢查藝術家和歌曲版本，尤其是現場錄音和混音。
  5. 單擊“使用所選歌詞”以應用該結果。

一些提供商需要憑據。 LRCLIB 整合支援同步和純文本歌詞。線上搜尋需要連線。

同步與純文本

同步歌詞包含時間戳，告訴播放器每行何時開始。簡單的歌詞提供了沒有這些時間的歌詞。如果出現文本但未跟隨歌曲，請檢查結果是否包含時間戳。您可以將它們新增到歌詞編輯器中。

保留本地副本

使用 LRC → 另存為… 將歌詞儲存到您選擇的檔案中。當您需要閱讀、卡拉 OK 計時或格式化時，首選 .lrcx。檢查您的儲存位置，以便您可以再次找到該檔案。

振假名與注音

歌詞閱讀輔助工具

振假名是顯示在日語歌詞旁邊的小號注音。羅馬字使用拉丁字母表示讀音。儲存的 LRCX Ruby 標記也可以提供手動編寫的注音。

選擇注音顯示

  1. 開啟設定→歌詞。
  2. 選擇 Global 作為一般預設值，或選擇 Local（檔案） 作為當前檔案。
  3. 啟用 顯示注音假名 、 顯示羅馬字 或 所有羅馬字 。這些模式是互斥的。
  4. 使用 Ruby 位置 將注音放在歌詞上方或下方。

選擇自動解析器

解析器要求
Yomi線上日語注音服務，需要連線網際網路。
MeCab本地可選解析器；需要fugashi和單獨安裝的字典。

解析器選擇器位於歌詞設定中。請參閱 設定 → 依賴關係 以獲取依賴關係資訊。

生成並糾正注音

開啟 LRC → 編輯 Lyrics，然後使用 Generation 選項卡。選擇 生成所有歌詞的注音 或 生成此時間戳 。自動讀取的名稱、異常拼寫和雙關語歌詞可能會出現錯誤；儲存前檢查它們。

要在 LRCX 中保留作者閱讀內容，請使用 {base|reading}，例如 {君|きみ}。請參閱 LRCX 參考 。

編輯和計時

糾正單詞並讓它們跟隨音樂

載入歌曲並選擇 LRC → 編輯歌詞。在進行重大時間更改之前儲存單獨的副本。

編輯歌詞行

在 Lyrics 選項卡中，選擇一行並編輯其文本。使用+新增行、刪除行、上移和下移來管理文件。格式控制元件包括粗體、斜體、刪除線、下劃線和 Quote。

設定線路時序

  1. 選擇您想要計時的線路。
  2. 使用編輯器播放控制元件查詢該行的開始位置。 Waveform 控制元件可幫助您檢查音訊。
  3. 在行開頭使用 標記播放時間 。這將更新所選行並前進到下一行。當調整臨時波形標記時，請使用 Commit 應用其時序。
  4. 再次播放該段落並檢查歌詞是否跟隨音樂。

使用 Shift Timing... 進行一致的時序調整，並使用 Validate Timing 檢查時序問題。在應用廣泛的轉變之前測試一小部分。

時間卡拉OK片段

在 Karaoke 選項卡中，使用 自動分離 準備段邊界，檢查它們，然後選擇 應用分離 。在處理片段時使用 Mark 播放時間 [F]。回聽以驗證結果；自動分離並不能保證準確的計時。

源文本與儲存

Source 選項卡顯示定時歌詞文本。 Refresh Source 和 Reload from Source 在結構化編輯器和源文本之間移動。在重新載入可能替換編輯的源之前儲存副本。

另存為 .lrcx 以保留 LRCX 功能。有關語法和示例，請參閱 LRCX 參考 。

LRCX參考

增強歌詞檔案的實用指南

LRCX 通過卡拉 OK 片段計時、Ruby 朗讀和文本格式擴充套件了 LRC。普通的 LRC 檔案仍然有效。

時間戳

[00:12.500]The line begins here
[00:16.000]<00:16.000>One <00:16.500>word <00:17.000>at a time

方括號時間戳標記行開始。尖括號時間戳標記卡拉 OK 片段的開始。時間使用分鐘、秒和毫秒。

Ruby 注音

[00:12.500]{君|きみ}の声

|之前的文本是基礎歌詞；後面的文字就是閱讀內容。

設定行格式和顯示行

語法效果
**bold**大膽
*italic*斜體
~~text~~刪除線
<u>text</u>下劃線
{\n}同一時間行中的新視覺行
> text緊接在行時間戳之後放置的塊引用
[00:12.500]**First row**{\n}Second row
[00:16.000]> A quoted lyric

視覺換行標記是文字文本 {\n}，而不是新時間戳。在編輯器中，使用 Insert Newline {\n}。

後設資料和相容性

[ar:Artist]
[ti:Song title]
[al:Album]

使用 .lrcx 擴充套件來保留這些增強功能。其他歌詞播放器可能無法理解副檔名。當您需要與其他播放器相容時，請保留普通的 LRC 副本。

有關完整的格式規範，請參閱專案源中的 LRCX_SPEC.md （可能需要 Markdown 閱讀器）。

定製化

讓玩家輕鬆閱讀和使用

外觀和背景

開啟 設定 → 外觀 選擇淺色或深色主題，更改強調色以及儲存、匯入或匯出主題。高階顏色控制可讓您調整單獨的介面顏色。

在 設定 → 背景 中，選擇藝術作品源或自定義背景資料夾並調整背景處理。如果歌詞文本難以閱讀，請從簡單的背景開始。

歌詞佈局

在 設定 → Lyrics 中，選擇緊湊或滾動顯示、書寫方向、對齊方式、字型和閱讀選項。自動滾動遵循時間戳；連續滾動的移動獨立於它們。滾動行為控制當前歌詞如何保持在檢視中。

全球還是本地？ 使用 全球 滿足您的正常喜好。檢查 本地（檔案） 當一首歌曲的表現與其他歌曲不同時。

卡拉OK外觀

使用 設定 → Karaoke 自定義卡拉 OK 顯示。逐字進行需要歌詞檔案中的分段計時；外觀設定無法新增缺失的計時。參見編輯和計時。

可選功能

其他設定和控制元件可能來自外掛，包括可選的配套功能和整合。開啟 Settings → Plugins 檢視您的安裝中可用的外掛及其設定。

外掛

管理可選功能

啟用並配置

  1. 開啟設定→外掛。
  2. 按名稱找到外掛並閱讀其說明。
  3. 使用其 Enabled 核取方塊來更改是否啟用。核心外掛無法停用。
  4. 如果出現 Settings 按鈕，請使用它來配置該外掛。

某些更改可能需要重新啟動應用程式。如果應用設定後未出現預期的控制元件，請重新啟動 LRCPlus。

依賴關係和載入錯誤

外掛可能需要額外的包。使用其 Dependencies 按鈕，或開啟 Settings → Dependencies，檢查依賴關係資訊。無法載入的外掛可能會在其設定條目中顯示錯誤；使用該訊息來識別缺失或衝突的需求。

新增外掛

外掛安裝特定於外掛和發行版。請遵循外掛作者的安裝說明。源專案從其 plugins 目錄中發現外掛；不要假設每個打包版本都公開相同的可寫位置。

對於外掛作者來說，單獨的 Plugin API 文件 涵蓋了開發（可能需要 Markdown 閱讀器）。

故障排除

從您可以看到的症狀開始

播放無聲

  1. 檢查播放是否正在執行且播放器未靜音。
  2. 檢查播放器音量和 Windows 混音器音量。
  3. 在 Settings → Playback 中，嘗試將 System Default 作為輸出裝置。
  4. 嘗試另一個已知有效的音訊檔案，看看問題是否特定於某首歌曲。

歌詞不出現

切換到歌詞。使用 Ctrl + L 顯式開啟歌詞檔案，或使用 LRC → 搜尋歌詞。檢查 設定 → 檔案 下的檔名和搜尋資料夾。如果LRC和LRCX檔案都存在，則先檢查LRCX檔案，因為LRCX檔案優先。

歌詞出現在錯誤的時間

確認歌詞與錄音相符：現場版本、混音版和不同的前奏通常有不同的時間安排。檢查檔案是否有時間戳。在編輯器中使用 Shift Timing... 以獲得一致的偏移，或者當整首歌曲中的不匹配發生變化時糾正單獨的行。

注音缺失或不正確

檢查設定→歌詞中的注音模式，包括任何本地（檔案）設定。 Yomi需要連線； MeCab 需要其本地包和字典。當單詞需要特定閱讀時，檢視自動輸出並使用編寫的 LRCX Ruby。

外掛不可用

檢視 Settings → Plugins 的啟用狀態和載入錯誤。檢查 Dependency 是否缺少所需的包。如果需要，配置更改後重新啟動。

報告問題

包括 Settings → About、Windows 版本、重現步驟、預期行為以及發生的情況中的 LRCPlus 版本。請注意其他曲目是否出現此問題以及是否涉及可選外掛。當有助於解釋時間或渲染問題時，請包含一個小歌詞示例。

播放器和歌詞工作區

  1. 圖書館工作區。 切換回您的音樂收藏；歌詞又回到了這個觀點。
  2. LRC 選單。 單擊LRC 可以編輯當前歌詞。它的箭頭可開啟“搜尋歌詞”、“另存為”和其他歌詞操作。
  3. 歌詞顯示。 此處出現同步歌詞。設定 → 歌詞控制顯示模式、字型、對齊方式和注音。
  4. 行列表。 展開或摺疊定時行列表。單擊展開列表中的一行可跳轉到其時間。
  5. 搜尋欄。 移動到另一個播放位置。在未載入音訊的情況下，持續時間和搜尋範圍保持為零。
  6. 播放或暫停。 暫停或恢復播放。相鄰按鈕可停止、跳過五秒或更改曲目。
  7. Volume. 調節音量；靜音使輸出靜音，而不丟棄儲存的音量級別。

圖書館工作區

  1. 搜尋庫。 過濾您的庫而不更改其檔案。
  2. 音樂庫。 新增資料夾後，曲目將顯示在此處。雙擊曲目即可播放；右鍵單擊列標題可管理可見列。
  3. 開啟檔案。開啟音訊載入檔案；新增到佇列追加檔案；開啟歌詞會附加歌詞檔案。
  4. Settings. 開啟首選項。使用類別列表和設定搜尋來查詢選項。
  5. 播放控制元件。 傳輸控制元件在兩個工作區中均保持可用。選中播放來源以選擇庫或佇列/播放列表。

歌詞編輯

  1. 編輯器工作區。 在歌詞、生成、源、共享和高階之間切換。可選外掛可以新增工作區。
  2. 定時歌詞行。 選擇要編輯的行。搜尋、上一個、下一個和順序選擇器有助於導航長文件。
  3. 標記播放時間。 在所選行上標記當前播放時間並前進到下一行。在計時之前載入音訊。
  4. Save. 儲存寫入更改並保持編輯器開啟。儲存並關閉寫入並退出；當沒有更改時，儲存將被停用。

設定視窗

  1. 設定類別。 選擇類別。類別上方的搜尋欄位可幫助按名稱查詢設定。
  2. 無間隙播放。 啟用下一曲目預緩衝。這需要FFmpeg和正常的速度和音調；它在下一曲目上生效。
  3. 輸出裝置。 選擇輸出裝置。系統預設值遵循系統選擇的輸出。

翻譯

將原始歌詞和翻譯行放在一起

選擇提供商

在設定 → 外掛中啟用 Lyrics Translator。載入帶有定時歌詞的歌曲並開啟 LRC → 編輯歌詞 → 翻譯。從提供商選擇器中選擇一個提供商。如果該選項卡不存在，請檢查翻譯提供程式是否已啟用並載入。

Argos 使用可選的本地包和下載的語言模型。雲提供商需要連線並且可能需要憑據。可用的提供商和語言路線顯示在應用程式中。

翻譯、審閱並儲存

  1. 如果當前歌詞文件尚未顯示，請將其載入到面板中。
  2. 選擇源語言和目標語言，然後選擇要翻譯的行或缺失的行。
  3. 選擇 翻譯缺失的行 或 翻譯選定的行 。讀取並編輯輸出；自動翻譯可能會漏掉名字、雙關語或上下文。
  4. 選擇應用到歌詞編輯器，然後使用儲存或儲存並關閉。

使用翻譯顯示行時，保留原始行並另存為 LRCX。 “歌詞”選項卡還具有 插入翻譯 {\nt}，用於在時間線內創作翻譯。

使用現有翻譯

搜尋歌詞包括原始和翻譯預覽。當結果提供翻譯的歌詞時，對其進行檢視並使用 Apply Only Translation 保留當前的原始文本。

如果無法翻譯

檢查提供商、語言路線、所需的型號或憑據以及連線。對於 Argos，檢查可選的依賴項和模型資料夾。對於雲服務，請注音服務錯誤。歌詞顯示語言和翻譯目標是單獨的選擇。

分享和影像卡

匯出文本或製作歌詞影像

複製或匯出文本

  1. 開啟LRC→編輯歌詞→分享→文本。
  2. 對於單獨的單詞，選擇 純文本 ；對於定時行，選擇 帶行時間戳 。
  3. 使用 Copy 作為剪貼簿，或使用 Export… 作為檔案。

這共享歌詞文本，而不是音訊。使用編輯器儲存操作來儲存完整的可編輯 LRCX 文件。

建立影像卡

  1. 在編輯器中開啟Share → 圖片卡。
  2. 使用選中的行選擇選擇摘錄並檢視預覽。
  3. 選擇佈局模板，然後調整文本、圖稿和背景設定。
  4. 使用卡控制元件匯出影像。

模板包括經典、聚光燈、唱片套、寶麗來、編輯和影院。藝術品是可選的；電影院可以使用專輯封面作為模糊背景。

閱讀和格式化

保留 LRCX 格式 保留內聯強調、引用樣式、視覺中斷和較小的翻譯行。漢字注音是單獨控制的，並使用創作的或已經生成的注音；影像卡不啟動注音服務。首先在編輯器中生成缺失的注音。

版式支援水平和垂直書寫。歌曲詳細資訊包括標題、藝術家或製作人員以及專輯。匯出前檢查預覽是否有被剪裁的文本或丟失的字型字元。卡上未列印時間戳和播放卡拉 OK 突出顯示。

同伴指南

Ayami 聊天、對話和儲存的記憶

開啟伴侶

Ayami 的可選聊天出現在啟用伴侶的設定嚮導中。使用 設定 → 常規 → 重新啟動向導 重新訪問設定。聊天與音樂播放是分開的，不需要配置來播放歌曲。

配置聊天

開啟 AI 設定... 並輸入相容提供商的 API 基本 URL、型號 ID 和金鑰。本地伺服器可能不需要金鑰。內建按鍵幫助解釋了提供程式設定。儲存，輸入訊息，然後選擇 Send。 Regenerate 請求另一個響應；停止取消正在執行的請求。

傳送與所選提供商共享對話、角色指令和啟用的記憶。不附帶歌曲、歌詞、設定。記住的金鑰和自定義標頭使用 Windows 帳號加密（如果可用）；否則它們仍僅用於會話。

儲存的對話

使用儲存的對話選擇器來切換聊天。 新對話開始另一個對話； Rename 和 Delete 管理已儲存的對話。上一頁和下一頁導航較長回覆的頁面。

控制儲存的記憶

開啟 Memories... 編輯事實，每行一個，並選擇是否將它們包含在以後的訊息中。最多允許 20 個事實，每個事實 200 個字元。

自動記憶模式提供關閉、建議批准（預設）和自動儲存普通偏好設定。提取可以使用額外的提供者請求。使用“審查”接受或駁回建議，使用“來源”檢查其來源，使用“立即檢查”請求檢查，或使用“停止檢查”取消建議。

工作教程

三個小任務，從開始到結束

為你的第一首歌計時

  1. 開啟音訊，然後開啟編輯器並按文件順序新增歌詞行。
  2. 選擇第一行並使用編輯器控制元件開始播放。
  3. 在該演唱行的開頭，選擇 標記播放時間 。編輯器對其進行標記並前進到下一行。
  4. 重複，然後回聽並糾正遲到或早到的分數。
  5. 選擇 Validate Timing，檢視結果並儲存副本。

從三到四行開始。逐段卡拉 OK 計時是可選卡拉 OK 選項卡中的單獨通道。

修復晚兩秒的歌詞

如果歌詞始終在歌手開始後兩秒出現，請將其時間戳 earlier 移動 2 秒。

  1. 儲存備份副本。
  2. 開啟 Shift Timing… 並選擇預期範圍，例如所有行。
  3. 使用對話方塊中顯示的單位輸入負的兩秒偏移（−2 秒或−2000 毫秒）。正值會稍後移動歌詞。
  4. 聽靠近開頭和結尾的地方。如果不匹配發生變化，請更正各個時間或查詢正確錄音的歌詞。
  5. 驗證並儲存。撤消可在編輯時反轉轉變。

Shift Timing 改變時間戳；單獨的歌詞偏移量保持不變。 [00:12.000] 處的線在移動 -2 秒後變為 [00:10.000]。

新增自定義注音假名

  1. 開啟歌詞文件，切換到Source。
  2. 儲存備份，然後使用 {base|reading} 換行。
  3. 例如，將 [00:12.500]君の声 更改為 [00:12.500]{君|きみ}の声。
  4. 使用 Source 中的 Reload 將源應用到結構化編輯器。
  5. 啟用顯示注音假名，檢查並儲存為.lrcx。

撰寫的讀物可讓您糾正姓名和不尋常的發音。
