私隱政策

最後更新： 2026年11月14日

本政策適用於 lrcplus.wiki 嘅 LRCPlus.wiki，同埋佢嘅社群帳戶、用戶頁面同討論。呢個 wiki 由我開發同維護。本政策唔涵蓋 LRCPlus 桌面應用程式，或者手冊連結嘅其他網站嘅資料處理方式。

我使用嘅資料

  • 帳戶：電郵地址、用戶名、帳戶識別碼、註冊同驗證資料，以及身份驗證紀錄。Supabase Auth 會處理你嘅密碼同登入工作階段，用嚟提供帳戶存取、驗證同重設密碼功能。公開用戶頁面唔會顯示你嘅電郵地址。
  • 公開貢獻：用戶名、公開帳戶識別碼、加入日期、用戶頁面自我介紹、討論主題、回覆同各自嘅時間。管理人員嘅角色亦可能會公開顯示。任何人都可以睇公開貢獻，搜尋引擎或者其他訪客亦可能會複製呢啲內容。
  • 管理：舉報、舉報詳情同被舉報內容嘅快照、管理人員操作，以及帳戶限制。呢啲紀錄用嚟防止濫用同進行審查，只有具備相應角色權限嘅管理人員先可以存取。
  • 技術資料：當你嘅瀏覽器連接託管、身份驗證同內容傳遞服務供應商時，對方會收到你嘅 IP 位址、瀏覽器詳情等連線資料。佢哋可能會按照自己嘅政策保留運作同安全紀錄。

我會用呢啲資料營運 wiki、管理帳戶、發佈貢獻、寄送帳戶相關電郵，同埋保護社群。你唔使開帳戶都可以睇手冊。請避免喺公開帖文入面加入敏感資料或者其他人嘅私人資料。

瀏覽器儲存

wiki 會將你嘅淺色或深色主題偏好儲存喺本機儲存空間。Supabase 亦會用瀏覽器儲存空間保持登入狀態同更新工作階段。你可以登出或者清除呢個網站嘅瀏覽器資料；清除資料可能會移除已儲存嘅偏好同登入工作階段。未提交嘅討論文字會喺你撰寫期間保留喺目前頁面。

服務供應商同跨國處理

wiki 用 GitHub Pages 提供網頁，用 Supabase 處理身份驗證同社群資料，再用 jsDelivr 傳遞 Supabase 瀏覽器程式庫。呢啲服務可能會按佢哋嘅基礎設施同資料庫專案所屬區域，喺多個國家處理資料。

wiki 冇加入廣告或者分析追蹤指令碼。公開內容會同讀者分享；我、有權限嘅管理人員同服務供應商會喺上述功能所需嘅範圍內使用帳戶同管理資料。適用法律要求嘅時候，亦可能會披露資料。

保留同刪除

帳戶資料會喺帳戶有效期間保留。公開個人檔案同貢獻會一直保留，直到被編輯或刪除；目前嘅社群系統唔會自動令佢哋到期。你可以用提供嘅功能修改自我介紹，同埋刪除自己嘅回覆。

刪除回覆會清除公開文字同作者歸屬，但會保留時間同已刪除標記，以維持討論結構。公開內容刪除之後，私人舉報快照同管理歷史可能仍然會保留，用嚟審查濫用行為同管理人員嘅決定。供應商紀錄同備份會跟隨各供應商嘅保留安排；喺線上 wiki 刪除內容，唔會即刻清除所有備份或者其他人整嘅副本。

你嘅選擇同私隱要求

按適用嘅資料保護法律，你可以要求了解處理情況、存取或更正個人資料、刪除資料、限制處理或反對處理，同埋喺處理依賴同意嘅情況下撤回同意。部分要求可能受法律例外限制。撤回同意可能會影響需要相關資料先運作到嘅功能。

你可以喺帳戶設定改電郵地址同密碼，亦可以喺用戶頁面修改公開自我介紹。想自行刪除帳戶，請打開帳戶設定，揀密碼同保安，再用刪除帳戶。輸入目前密碼，再確認永久刪除。

刪除帳戶會移除登入資料、個人檔案同自我介紹。現有討論文字會移除帳戶關聯後保留；帖文入面嘅文字仍然可能畀人認出你。如果想刪除回覆嘅公開文字，請喺刪除帳戶之前先刪除嗰啲回覆。如上所述，私人舉報快照同管理歷史可能仍然會保留。刪除無法復原。

提出私隱要求唔會限制你按適用法律向主管機關投訴或者尋求其他補救嘅權利。

私隱聯絡方式

我暫時仲未有專用嘅私隱聯絡電郵。聯絡地址確定之後，我會更新呢個頁面。你可以用上述帳戶、自我介紹同回覆功能直接管理自己嘅資料。

本政策嘅更改

wiki 嘅資料處理方式改變時，我會更新呢個頁面同上面嘅日期。如果改動需要額外通知或者同意，我會喺相關處理開始之前提供通知或者取得同意。
